Privacy Policy

This Privacy Policy describes how the LifeCue iOS application (“LifeCue,” “the app”) handles information. It is based on the current LifeCue V1 implementation.

LifeCue is designed to work on your iPhone without creating an account. Reminder data is stored using Apple SwiftData on the device. LifeCue’s source code does not include a LifeCue backend, cloud database, analytics SDK, crash-reporting SDK, or advertising SDK, and it does not call cloud LLM APIs.

This policy does not claim that information can never leave your device. You can export a backup file or forward reminder text using Apple’s system sharing and document interfaces. Those destinations are chosen by you. In addition, Apple’s operating system may include app data in an iOS device backup if you have device backup enabled. LifeCue does not implement its own iCloud or CloudKit sync.

Privacy at a Glance

Account LifeCue does not require registration or login.
Where data is stored Reminders, People, and Contexts are stored locally with SwiftData. Preferences such as appearance and default reminder time are stored in UserDefaults.
LifeCue servers The app source does not include LifeCue server or API communication.
Analytics and ads No analytics, crash-reporting, or advertising SDKs are present in the project.
Photos Images are used to extract reminder details on the device. Image bytes are not part of the SwiftData reminder, person, or context records.
Your exports Backup files and forwarded text leave LifeCue only when you choose Export Backup or Forward and pick a destination.

Information the App Stores

On your device, LifeCue stores:

  • Reminders — title, event date, optional time, time zone, optional note, optional links to a Person and Context, status (active or completed), schedule rules, optional snooze time, and timestamps.
  • People (optional) — name, optional relationship, display icon and color, archived flag, and timestamps. People records do not include phone numbers, email addresses, or similar contact fields.
  • Contexts (optional) — name, optional associated Person, display icon and color, archived flag, and timestamps.
  • Settings — appearance (system, light, or dark) and default reminder time, in UserDefaults.
  • Backup reminder preferences — whether a local backup reminder notification is enabled, the interval you chose, and the last-export timestamp recorded on this device.

Local notifications scheduled by LifeCue include the reminder title and a date/time summary. Backup reminder notifications use a fixed title and body that do not include reminder contents.

Calendar events are read from Apple Calendar (EventKit) when you use Calendar features. LifeCue does not write calendar events and does not persist your calendar database inside LifeCue’s SwiftData store.

Photos and Image Information

You can create a reminder draft from a photo by using the camera, choosing an image with the system photo picker, or uploading an image from within LifeCue. LifeCue does not appear in the iOS incoming Share Sheet.

Text is recognized on the device using Apple’s Vision framework (VNRecognizeTextRequest). A local deterministic parser then proposes reminder fields such as title, date, time, and note. Extraction can be incomplete or incorrect. You review and confirm before a reminder is created. LifeCue does not schedule a notification from an unconfirmed draft.

The project does not use VisionKit, Foundation Models, Apple Intelligence APIs, or cloud OCR APIs. Image processing is performed by Apple Vision and LifeCue’s local parser.

SwiftData reminder, person, and context records do not store image files. If you confirm a reminder after extraction, LifeCue stores the reminder fields you confirm (for example title, date, time, and note), not the original photo. Recognized text is not written to application logs in the OCR modules.

LifeCue does not include code that uploads images to a LifeCue server. There is no photo-library “add-only” or full-library usage string in the project; photo selection uses the system picker.

Reminders

Reminders are created in the app, stored locally, and can trigger local notifications through UserNotifications. You can complete, edit, snooze, reschedule, or delete reminders in the app. Deleting a reminder removes it from the local store and cancels its LifeCue-scheduled notifications.

Forward creates editable plain text from a reminder and presents Apple’s share sheet. LifeCue does not send that text itself. If you share to Messages, Mail, or another destination, that destination’s privacy terms apply.

People and Contexts

People and Contexts are optional labels you can create to organize reminders. They are stored locally. The same context name can exist for different people as separate records. LifeCue does not require you to add people or contexts in order to create a reminder.

Backup and Restore

LifeCue does not automatically create backup files. When you choose Export Backup, the app writes a .lifecuebackup JSON document and presents the system file exporter so you can save it to Files, iCloud Drive, another location provided by iOS, AirDrop, or a third-party storage app you have installed.

A backup file contains your People, Contexts, and Reminders (including notes, schedule rules, and related identifiers). It does not include notification request identifiers or image files. Restore replaces current LifeCue data on the device with the contents of a valid backup you import. Invalid or unsupported backups are rejected and leave existing device data unchanged.

Optional Backup Reminder is a local notification that reminds you to export. It does not create or upload a backup.

Permissions

LifeCue requests system permissions only for features that need them:

  • Camera — so you can capture a photo of a note or document to read on the device. Requested when you use Camera.
  • Calendar (full access) — so LifeCue can optionally show upcoming calendar events and prefill reminder details. Requested when you use Calendar features. LifeCue’s calendar code is read-only; it does not create or modify calendar events.
  • Notifications — so LifeCue can deliver local reminder alerts and, if enabled, backup reminders. Requested when scheduling requires authorization.

You can deny any permission. Camera, Calendar, and notifications are not required to create a manual reminder. You can change permissions later in iOS Settings.

Data Sharing and Third Parties

The LifeCue Xcode project does not include third-party analytics, advertising, crash-reporting, or social SDKs. It does not include a LifeCue backend or account service.

LifeCue uses Apple frameworks on the device, including SwiftUI, SwiftData, Vision, EventKit, UserNotifications, PhotosUI, and UIKit.

LifeCue does not sell personal information. The app does not transmit reminder contents to a LifeCue-operated service because no such service is implemented.

Information may leave the LifeCue app when you:

  • export a backup and save or send the file somewhere you choose;
  • forward reminder text through the system share sheet;
  • use Apple services that are part of iOS (for example device backup, if you enable it on the iPhone).

Those destinations are not operated by LifeCue. Their own policies apply.

Data Retention and Deletion

LifeCue keeps reminder, person, and context records on the device until you delete them in the app, replace them by restoring a backup, or remove the app from the device.

Deleting LifeCue from the iPhone removes the app’s sandbox data on that device. Copies you previously exported (backup files) or forwarded remain wherever you saved or sent them. If you use iOS device backup, Apple’s backup may still contain a copy of app data according to your iPhone backup settings.

Children’s Privacy

LifeCue does not provide a child account, family sharing product, or age-gate. It does not collect information on LifeCue-operated servers. If you allow a child to use LifeCue on a device you control, the reminder data they enter is stored locally on that device like any other LifeCue data.

If you believe a child has used LifeCue in a way that concerns you, delete the relevant reminders or the app on that device, and contact us using the address below.

Security

LifeCue stores application data in the iOS app sandbox using SwiftData and UserDefaults. Access to Camera, Calendar, and Notifications is mediated by iOS permission prompts.

A backup file is an unencrypted JSON document. Anyone who can open that file can read the reminders, People, and Contexts inside it. Store exported backups in a place you trust.

No method of storage or transmission is perfectly secure. LifeCue does not operate a network service that would receive your reminders.

Support

If something is not working, try the following:

  • Confirm LifeCue has notification permission in iOS Settings if alerts are missing.
  • Confirm calendar permission if Calendar events do not appear.
  • Review extracted image details before creating a reminder; extraction is not always accurate.
  • Export a backup before restoring, because restore replaces current LifeCue data on the device.

Contact support at teamcentersap@gmail.com. Please include the iOS version and a short description of the problem. Do not send screenshots that contain information you do not want stored in email.

How to Use LifeCue

Create a reminder

Open LifeCue and tap +. Choose Add Reminder, Photo, Camera, or Upload. Fill in or review the details, then create the reminder. Date-only reminders use the default reminder time from Settings in the reminder’s stored time zone.

People and Contexts

Both are optional. Use People for who a reminder is for, and Contexts for categories such as school or health. The same context name can exist separately for different people.

Calendar

LifeCue does not replace Apple Calendar. You can view upcoming events and prefill a reminder. LifeCue does not automatically create calendar events or reminders from the calendar.

Image extraction

Use Photo, Camera, or Upload. Always review title, date, time, and note before creating the reminder.

Notifications

Use Repeat, Limit Dates, and Remind me to control recurrence and when alerts fire relative to the event.

Forward

Open a reminder and choose Forward. You can edit the text before sharing. Editing the forwarded text does not change the stored reminder.

Backup

Use Backup & Restore → Export Backup to create a .lifecuebackup file, then save it where you choose. Use Import Backup to restore. Backup Reminder only reminds you to export; it does not back up automatically.
